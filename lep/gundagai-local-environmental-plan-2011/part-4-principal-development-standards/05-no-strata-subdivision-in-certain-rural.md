# 4.2B No strata subdivision in certain rural zones

**(1)**
The objective of this clause is to ensure that land to which this clause applies is not fragmented by subdivisions that would create additional dwelling entitlements.

**(2)**
This clause applies to land in the following zones that is used, or proposed to be used, for residential accommodation—
- (a) Zone RU1 Primary Production,
- (b) Zone RU4 Primary Production Small Lots.

**(3)**
Development consent must not be granted for the subdivision of a lot to which this clause applies for a strata plan that would create lots below the minimum size shown on the *Lot Size Map* for that lot.
