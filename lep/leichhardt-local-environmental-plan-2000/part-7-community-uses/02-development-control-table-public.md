# 28 Development control table: Public Purpose Zone

The following Table applies to development within the Public Purpose Zone—
Table Description of the zone The Public Purpose Zone enables land to be developed for public, community and cultural purposes. Land within this zone is shown coloured yellow on the Zoning Map.
