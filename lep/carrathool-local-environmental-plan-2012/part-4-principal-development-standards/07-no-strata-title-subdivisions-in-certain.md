# 4.2C No strata title subdivisions in certain rural and residential zones

**(1)**
The objective of this clause is to ensure that land to which this clause applies is not fragmented by subdivisions that would create additional dwelling entitlements.

**(2)**
This clause applies to land in the following zones that is used, or proposed to be used, for residential accommodation or tourist or visitor accommodation—
- (a) Zone RU1 Primary Production,
- (b) Zone R5 Large Lot Residential.

**(3)**
Development consent must not be granted for the subdivision of land to which this clause applies for a strata plan that would create lots below the minimum lot size shown on the *Lot Size Map* for that lot.
