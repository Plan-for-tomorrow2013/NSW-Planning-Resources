# 5.1A Development on land intended to be acquired for public purposes

**(1)**
The objective of this clause is to protect land that is intended to be acquired for a public purpose.

**(2)**
Development consent must not be granted to any development on land identified on the *Land Reservation Acquisition Map* to be acquired for a public purpose unless the consent authority is satisfied that the development is likely to be consistent with the public purpose identified on that map for that land.
