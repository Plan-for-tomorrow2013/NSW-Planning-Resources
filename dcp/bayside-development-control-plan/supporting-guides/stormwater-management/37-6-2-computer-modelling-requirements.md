### 6.2 Computer modelling requirements:

Bayside Councils preference is to utilise DRAINS software in designing the OSD system. Where the DRAINS

(ILSAX) model is used in the design to calculate the required design volume, the following design parameters

are to be adopted:

• soil type = 3

• antecedent moisture content, AMC = 3

• depression storage - paved area = 1 mm, supplementary area = 1mm, grassed area = 5 mm

• Rainfall and temporal patterns, as per Australian Rainfall and Runoff (current edition) Where the DRAINS (IL-CL) model is used in the design to calculate the required design volume, initial and

continuing loss assumption need to be in accordance with the Australian Rainfall and Runoff (AR&R) data hub

data and latest AR&R guidelines. A soft copy of the drains modelling will need to be provided to council for

review along with a detailed breakdown/output of the modelling data within a supplementary report.
