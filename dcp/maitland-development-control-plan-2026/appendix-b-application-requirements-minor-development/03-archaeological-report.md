## 3. ARCHAEOLOGICAL REPORT

An archaeological report is to be prepared by a qualified archaeologist. An archaeological report is a document that summarises the results of an archaeological investigation and provides an objective account of the findings. It includes information about the research questions, methods, data, and artifacts, and uses this information to draw conclusions about past human life.
