#### 6.11.1. Swimming Pools

#### Objectives

O.85 To ensure that swimming pools do not have an adverse impact on surrounding properties. O.86 To ensure that swimming pools are appropriately sited and designed. O.87 To ensure that the bulk and scale of a swimming pool is consistent across residential areas.

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.1 | Swimming pools are to maintain compliance with the applicable Residential Uses controls and acceptable solutions, including, but not limited to, landscaped area, impervious area, and PPOS. These controls are provided in Section 6.2 of this Chapter. |
| • O.85 |  |
| • O.86 |  |
| PC.2 | Swimming pools are to be located behind the dwelling’s primary street building line and, if applicable, behind the dwelling’s secondary street building line. |
| • O.85 |  |
| • O.86 |  |
| PC.3 • O.86 | At least 1m of clear space is to be provided around the swimming pool. The swimming pool may encroach the dwelling’s rear setback provided that the 1m of clear space is maintained. |
| PC.4 | Swimming pool decking is to be a maximum of 1.4m above existing ground level. |
| • O.86 |  |
| PC.5 | Coping width is to be a maximum of 0.3m wide if more than 0.6m above existing ground level. |
| • O.86 |  |
| • O.86 |  |
| PC.6 | If a swimming pool has a proposed capacity equal to or more than 40,000L, it must be accompanied by a compliant BASIX certificate. |
| • O.86 |  |
| PC.7 | For swimming pools in rural areas, the proposed design and location is not to impact upon on-site sewage management systems and any associated effluent disposal areas. |
| • O.86 |  |
| PC.8 | Any swimming pool pump provided is to be contained in a noise-proofed enclosure. |
| • O.85 |  |
| • O.86 |  |
| PC.9 | Child resistant barriers are to be installed and constructed in accordance with the requirements of the Swimming Pools Act 1992 (or as amended). |
| • O.86 |  |
