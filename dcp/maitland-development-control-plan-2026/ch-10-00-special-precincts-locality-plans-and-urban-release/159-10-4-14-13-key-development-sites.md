#### 10.4.14.13. Key Development Sites

#### Objectives

O.479 To ensure that detailed urban design controls are provided for signiﬁcant development sites.

Ridgelines and Slopes

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.1 • O.479 | A Visual and Scenic Impact Assessment is to be prepared to help inform the subdivision design and layout and must include landscaping measures to protect the prominent skyline. |
| PC.2 | Development along and near ridgelines and slopes are to retain existing vegetation to screen and break up visual impacts. |
| • O.479 |  |
| PC.3 • O.479 | Areas along the ridgelines are to include larger allotments of a minimum 3000m², so as to provide adequate land area to include new buildings, generous setbacks and appropriate landscaping. |
| PC.4 | Subdivision design plans are to include cross-section plans for lots adjoining the ridgeline detailing building envelopes and buildings below the ridgeline. |
| • O.479 |  |

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| AS.1 | A limited number of large allotments will be considered so as to sustainably maintain and manage the residual rural lands in accordance with the current Maitland LEP zoning. |
| • O.479 |  |
| PC.5 | Fencing of such allotments is to be of timber post and rail style (or similar) so as to minimise any visual impacts of development. |
| • O.479 |  |
