#### 10.4.2.25. Overall Landscaping Strategy

#### Objectives

O.89 To soften the visual impact of all built elements, creating attractive and consistent streetscapes

when viewed by passing traffic and pedestrians.

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.1 | Landscaping is to be provided on land adjacent to Aberglasslyn Road. |
| • O.89 |  |
| PC.2 | Existing trees are to be retained wherever possible within riparian corridors, open space, within and adjacent to the Aberglasslyn Road reserve and along allotment boundaries. |
| • O.89 |  |
| PC.3 | Retained drainage lines/watercourses are to be re-vegetated to enhance visual amenity, prevent soil erosion and help protect the quality of receiving waters. |
| • O.89 |  |
| AS.1 | Landscaping of the private and public domain is to be generally consistent with the landscape concepts shown in Figure 10-22. |
| • O.89 |  |
| PC.4 • O.89 | Development Applications for subdivision are to include detailed landscaping plans identifying appropriate street tree species, and, where applicable, the following: a. landscaping treatments to Aberglasslyn Road, b. fencing/landscaping treatments within the acoustic buffer running parallel to the railway line, c. landscaping treatments of key intersections, and d. how open space areas and trunk drainage are to be located and landscaped. |
