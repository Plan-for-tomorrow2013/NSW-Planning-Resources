#### 10.4.3.5. Amelioration of Natural and Environmental Hazards

#### Objectives

O.105 Amelioration of natural and environmental hazards, including bushﬁre, ﬂooding and site

contamination and, in relation to natural hazards, the safe occupation of, and the evacuation from, any land so affected is achieved.

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.1 | Flood free access is to be available to all proposed allotments. |
| • O.105 |  |
| PC.2 | Development must comply with the relevant provisions of Planning for Bush Fire Protection 2019. |
| • O.105 |  |
| PC.3 | Land within the flood planning area is to address Clause 5.21 of the Maitland Local Environmental Plan 2011. |
| • O.105 |  |
| PC.4 | All development applications must demonstrate compliance with the requirements of the State Environmental Planning Policy (Resilience and Hazards) 2021. |
| • O.105 |  |

#### Land adjoining Cessnock Road Objectives

O.106 Detailed urban design controls are provided for signiﬁcant development sites to assist in providing

separation to traffic noise and a streetscape view of the front of dwellings and landscaped gardens.

O.107 To ensure that fencing does not form a prominent element in the landscape along the road corridor.

O.108 To ensure that future residential development is not adversely affected by noise and vibration from

Cessnock Road.

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.1 | A buffer (incorporating 10m for road widening and landscaping) is to be established on land adjoining the eastern side of Cessnock Road, north of Russell Street as shown on Figure 10-26 and Figure 10-27. Details of the landscape buffer is to be provided in a landscape plan with any development application for the site. |
| • O.106 |  |
| • O.107 |  |
| • O.108 |  |
| PC.2 | An independent acoustic assessment is to be submitted with any development application identifying levels of impact and noise attenuating measures for future residential development in accordance with Transport for NSW and DCCEEW requirements. |
| • O.106 |  |
| • O.108 |  |
| PC.3 | No future lot is to have direct access to Cessnock Road (MR 195). |
| • O.106 |  |
| • O.108 |  |
| PC.4 • O.107 | Fencing of allotments along the boundary of Cessnock Road is to be of consistent materials and colour and form an integral part of the landscape plan provided with the development application. |

#### Rural Land / Flood Fringe Interface Objectives

O.109 To ensure detailed urban design controls are provided for development site adjoining rural and

ﬂood-affected lands.

| PRESCRIPTIVE CONTROLS AND ACCEPTABLE SOLUTIONS |  |
|---|---|
| PC.5 • O.109 | A perimeter road (with development on the inner side only) is to be provided around the edge of the Precinct where it adjoins flood prone land, rural land or land zoned for environmental protection. |
| PC.6 | An off-road shared path is to be provided on the lower side of the perimeter road to create a continuous pathway. |
| • O.109 |  |
| PC.7 • O.109 | Fencing is to make a positive contribution to the visual appearance of development and will be consistent with the overall landscaping strategy. Fencing adjacent to the boundaries of the surrounding rural lands and visually sensitive areas shown on the Precinct Plan must be unobtrusive, compatible with the rural character, and may include timber post and rail style. Details of fencing are required to be submitted to Council with development applications. |
| PC.8 | Development adjacent to rural zones and flood prone lands are to be suitably designed so as to be compatible with the existing rural landscape and setting. |
| • O.109 |  |
| PC.9 | Access to allotments adjacent to rural zones and flood prone lands are to be flood free and at appropriate gradients, with minimal earthworks. |
| • O.109 |  |
| PC.10 | Any fencing of allotments in flood prone areas is to be designed so as not to restrict or divert flood waters. |
| • O.109 |  |
