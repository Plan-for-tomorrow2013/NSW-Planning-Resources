### 2.3 The standard bin dimensions are:

| Standard bin type | Dimensions |  |  |
|---|---|---|---|
|  | Height | Height | Height |
| 140L mobile garbage bin | 930mm | 530mm | 610mm |
| 240L mobile garbage bin | 1,060mm | 580mm | 730mm |
| 660L bulk bin | 1,250mm | 1,370mm | 850mm |
| 1,100L bulk bin | 1,470mm | 1,370mm | 1,245mm |
| Hook lift/compactor bin (10m3–30m3) | 2.5m | 2.5m | 6m |

Note: Dimensions are a guide only and may differ depending on the manufacturer. An additional 15cm is to be provided around each bin in the design of the waste bin storage area, to ensure it can function effectively and efficiently, and to avoid damage to walls and doors from bins scraping against them.
