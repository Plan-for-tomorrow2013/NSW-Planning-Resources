### 4.6 APPROPRIATE VEGETATION

To provide quick soil surface stabilisation, either turf or a cover crop of grasses should be immediately established as the work progresses.  The following seed types are provided as a guideline only, allowances should be made for the type of flow, either sheet or diverted which may require turf, fabric.

| Type | Spring/Summer | Autumn/Winter |
|---|---|---|
| Japanese Millet | 4kg/ha | - |
| Couch (hulled/unhulled) | 4kg/ha | 4kg/ha |
| Ryecorn/Barley | - | 30kg/ha |
| Red Clover | 4kg/ha | 4kg/ha |
| White Clover | 4kg/ha | 4kg/ha |
| Wimmera Rye | 10kg/ha | - |
| Perennial Rye | - | 10kg/ha |
| Kikuyu | 4kg/ha | - |
