**Note on the 30 Floss Street photo:** unlike the six boundary maps (purely locational), this
figure is directly operative — the "Additional setback and height controls" clauses in
Section 3 define maximum height by reference to features marked on this image (the parapet
cornice line). A reader relying only on the converted text will be missing the visual
reference point the control depends on. Recommend prioritising this one for image-asset
conversion ahead of the plain boundary maps if resourcing is limited.
