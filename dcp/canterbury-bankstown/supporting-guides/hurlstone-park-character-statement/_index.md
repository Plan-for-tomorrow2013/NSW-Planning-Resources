# Character Statement — Hurlstone Park Heritage Conservation Areas

Canterbury-Bankstown Development Control Plan 2023, supporting document for Chapter 4
(Heritage). Sets out the statement of significance, key character elements, and per-property
building contribution rankings for six Heritage Conservation Areas (HCAs) in Hurlstone Park.

**Scope note:** This document is council-wide in the sense that it isn't split by former LGA,
but unlike a typical "general/" chapter it only covers Hurlstone Park precincts — it is a
sibling document to other suburb-specific Character Statements (e.g. "Character Statement –
Ashbury HCA", seen in Council's guide index but not yet converted). See the placement flag in
the top-level note below.

Front matter across every section in this document omits `effective_date`/`amended_date`
(source gives only "June 2023 (Amended April 2025)", no day) and `zones` (not stated in the
source — it identifies areas by street/property address rather than by zone).
