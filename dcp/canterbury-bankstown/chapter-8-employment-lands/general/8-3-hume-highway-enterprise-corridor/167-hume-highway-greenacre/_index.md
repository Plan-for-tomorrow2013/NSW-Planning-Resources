## Section 6 — Greenacre Motor Alley (167 Hume Highway in Greenacre)

A self-contained, site-specific mini-DCP for a single 11,750m² lot (Lot 402, DP 631754),
currently a standalone hotel, being planned for mixed-use redevelopment. Split into one
file per numbered subsection (6.1–6.15) rather than a single Section 6 file, because this
subsection functions as its own multi-part precinct DCP — the same reasoning the
conversion guide applies to give a sub-document its own folder once it has 2+ internal
sections.

### Anomalies flagged during conversion (specific to this subsection)

1. **Three-tier precedence stack** — the Apartment Design Guide prevails over this
   subsection for residential matters (except where the Housing SEPP itself says
   otherwise), while this subsection prevails over other DCP chapters generally. See the
   note in `01-site-and-application.md`.
2. **Naming inconsistency**: Section 4's Explanation calls the neighbouring precinct "the
   Rookwood Road Village" once, vs "Rookwood Village Centre" everywhere else — noted
   there, not here, but relevant since 167 Hume Highway sits within the broader Greenacre
   Motor Alley precinct adjoining Rookwood Village Centre.
3. **6.12 and 6.13 have no "Objectives" heading**, unlike every other subsection —
   reproduced as printed (development controls only), flagged in each file rather than
   fabricating objectives that aren't in the source.
4. **Table 3 (6.7.2) has a gap**: the front (Hume Highway) setback table gives figures for
   floors 1–3 (12m) and floors 5–6 (15m) but no explicit figure for the fourth floor. See
   the anomaly note in `06-built-form.md`.
5. **Tree-planting standard conflict (not really a conflict, but worth surfacing)**: this
   subsection's own landscaping clause (6.10 C6: 100L pots, local native species) is more
   specific/stringent than the chapter-wide Section 3 standard (75L pots, Appendix 1
   species list) that would otherwise apply to any E3 site on the highway. Since 6.2
   states this subsection's controls prevail for 167 Hume Highway specifically, C6 governs
   here. See the note in `09-landscaping-and-public-domain.md`.
6. This subsection's drafting style (objectives + lettered "C" development controls under
   numbered sub-headings, site-specific desired character narrative, indicative structure
   plan) closely matches the newer Chapter 7 precinct-DCP style (7.5/7.6/7.7) rather than
   the older sequential-clause style used in the rest of Chapter 8.3 (Sections 3–5, 7–8).
   Both this subsection and 8.2 (Canterbury Road) date to the same April 2025 amendment
   as the rest of the chapter, but structurally read as if drafted separately/later — worth
   keeping in mind for the cross-chapter drafting-template reconciliation pass already
   flagged for Chapter 7.
