### Notes
- **Chapter 1** in Council's numbering appeared as "1.1 Introduction and Administration" in the source PDFs seen so far — confirm whether Chapter 1 has further sub-chapters (1.2, 1.3...) once that PDF is reconverted.
- **Chapter 4 (Heritage)** is council-wide, not split by former LGA — all four sub-chapters (4.1–4.4) sit under `chapter-4-heritage/general/`. Chapter 4.3 has one Ashbury-HCA-specific section and one Hurlstone-Park-specific section internal to that single document; this is not a former-LGA folder split. Chapter 4.4 is a single-section sub-document kept as a flat file per the conversion guide, rather than its own folder. See `chapter-4-heritage/_index.md` for two follow-up documents needed (Heritage Guide; Heritage Conservation Area Character Statements) and each sub-chapter's own `_index.md` for source anomalies flagged during conversion (a duplicate clause label, an apparently incomplete clause, and minor cross-chapter wording differences).
- **Chapter 5** is the only chapter confirmed so far to split by former LGA. Don't assume other chapters split the same way — check each chapter's own "Application of this chapter" wording before deciding whether it needs an LGA-level subfolder. Chapter 3 was checked sub-chapter by sub-chapter during its conversion: only 3.4 (Sustainable Development) has an "Application of this chapter" section, and none of the seven Chapter 3 sub-chapters split by former LGA (see chapter-3-general-requirements/_index.md for the reasoning). Chapter 4 was likewise checked sub-chapter by sub-chapter and found not to split by former LGA. **Chapter 7.6 was checked this session and also does not split by former LGA** — clause 1.1 defines the Precinct as the Belmore and Lakemba local centres together, with no LGA-based application wording.
- Folders for "not started" chapters are intentionally not created yet — create them only when there's a converted file to put in them, so an empty folder never implies work that hasn't happened.
- **Chapter 6 (Strategic Centres)** splits by **strategic centre**, not by former LGA — a new scope-split pattern for this repo (Chapter 5 splits by former LGA; Chapter 4 is fully council-wide "general"). 6.1 (General Requirements) applies across both centres and sits in `chapter-6-strategic-centres/general/`; 6.3 (Campsie Town Centre) is centre-specific and sits in `chapter-6-strategic-centres/campsie-town-centre/`. 6.2 (Bankstown City Centre) has **not** been converted — at 221 pages it's roughly 10–20x the size of any other sub-chapter converted so far in this repo, with its own multi-level section numbering (Sections 1–6, a "Part 5," and an Appendix). See `chapter-6-strategic-centres/_index.md` for its full structure and a recommended approach for converting it in dedicated parts rather than in one pass. Source anomalies found in 6.1 and 6.3 (a section-heading singular/plural mismatch, an unnumbered clause-support paragraph, a figure-caption/clause percentage mismatch, and a scope ambiguity in an "Exceptions" clause) are flagged in each sub-chapter's own `_index.md`.
- **Chapter 7 (Commercial Centres)** combines *four* different scope patterns in one chapter — see `chapter-7-commercial-centres/_index.md` for the full breakdown: 7.1 (General Requirements) is council-wide across all of Chapter 7 (like 6.1); 7.4 (Neighbourhood Centres) is council-wide but scoped to 'Area 1' land only; 7.2 (City West) and 7.3 (City East) split by geographic grouping with one boilerplate section per named centre (a new pattern — not former-LGA, not strategic-centre); and 7.5/7.6/7.7 (Canterbury Local Centre / Belmore and Lakemba / Punchbowl and Wiley Park) are newer, much more detailed standalone "precinct DCP" chapters (Understanding Place, Public Domain Design, Building Design, General Provisions, Key Sites, Appendices) that explicitly supersede older centre sections previously inside 7.3, each via its own clause-1.1 precedence wording — **confirmed directly** in both 7.7's and (as of this session) 7.6's clause 1.1 text. **Notable anomaly**: 7.3's Contents page flags Belmore/Lakemba/Punchbowl/Wiley Park as replaced by 7.6/7.7, but does *not* flag Section 4 (Canterbury) as replaced by 7.5, even though 7.5's own precedence clause means it governs Canterbury regardless — Council's Contents page/explanatory text for 7.3 is simply stale on this point. 7.1, 7.2, 7.3, 7.4 and 7.7 are fully converted. **7.6 is now in progress (2 of 7 sections converted this session)** — see `chapter-7-commercial-centres/belmore-and-lakemba/_index.md` for the page map to resume from Section 3 (page 40). 7.5's status is still unconfirmed; the earlier inference from 7.7's scaffold text that 7.5/7.6 might already be complete has now been shown wrong for 7.6, so treat it with caution for 7.5 too — verify directly.
