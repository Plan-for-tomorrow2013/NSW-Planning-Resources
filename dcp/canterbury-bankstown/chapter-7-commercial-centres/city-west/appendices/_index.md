## Figures not converted (image only)

Every figure referenced across Sections 1–13 and Appendix 1 is image-only content (maps,
precinct plans, setback diagrams, building envelope plans) and has not been converted.
Each section file notes its own figures inline (`> See Figure...`) and lists them under a
`## Figures` heading. This index does not duplicate the full per-section figure list — see
each section file for that.

Notable figure groups:

- **Land Application Maps** — one per centre (Figures 2a, 3a, 4a, 5a, 6a, 7a, 8a, 9a, 10a,
  11a, 12a, 13a), showing the land to which each section applies.
- **Precinct Plans** — for centres split into functional/physical precincts (Figures 3b, 6b,
  8b, 9b, 10b, 11b, 13b), sourced from the relevant Local Area Plan.
- **Setback control plans** — one per centre that uses the Appendix 1 setback typology
  system (Figures 3d/3e, 5c, 6d, 8d, 9d, 10d, 11d, 13d).
- **Site-specific building envelope/setback figures** — Bass Hill (Figures 2c–2i), Padstow
  (Figures 9e–9h), Revesby (Figures 11e–11f), Yagoona (Figure 13e), Chester Hill (Figure
  4c).
- **Appendix 1 setback typology diagrams** — Figures 1–18, illustrating Setback Types
  F1, F1A, F2, F3, F4, F4A, F5, F6, R1, R1A, R2, R3, R4, R5, R6, S1, S2, S3.
- **Indicative house type diagrams (Types A–J)** — pages 98–108 of the source PDF,
  referenced from the Appendix 2 lot schedule's "Indicative house" column. Entirely
  image content (floor plans/elevations), no extractable text.
