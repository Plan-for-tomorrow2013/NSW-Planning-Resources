# Land Use Matrix for draft LEPs

## Instructions (from the INSTRUCTIONS sheet, word for word)

[DPE version 4.3]
August 2020

**LAND USE MATRIX for draft LEPs**

### What the matrix is for

A 'matrix' of defined land use terms and standard zones is available to assist councils preparing LEPs. Councils can complete the matrix of intended permitted and prohibited land uses to assist in discussions with the Department about their draft plan.

### How to fill in the matrix

1. Open the Matrix page.

2. Put in [Name of LGA] and [Year] in the upper left hand corner (ie. 'name of Plan' as per clause 1.1 of the Standard Instrument).

3. Select Y/N (ie. yes or no) from the dropdown menu underneath the name of each zone to indicate if a particular zone is used.

   Zone E1 National Parks and Nature Reserves is not included given there is no need to add any additional land uses to this zone.

4. Complete the entire columns for the zones in use. Fill in each cell with o, c or x:

   - **o** permitted without consent.
   - **c** permitted with consent.
   - **x** prohibited.

   There is no need to amend the cells which are pre-filled with the following symbols:

   - **o** permitted without consent [mandated under the SI].
   - **c** permitted with consent [mandated under the SI].
   - **x** prohibited [mandated under the SI].
   - **H** permitted under the SEPP (Housing) 2021.
   - **TI** permitted under the SEPP (Transport & Infrastructure) 2021 [applicable to both public & private infrastructure].

   Some cells are pre-filled with the following symbols which indicate that:

   - **\*** the use must be included as permitted with or without consent - please select o or c.
   - **#** the use may (but need not) be permitted with consent - please select c or x.

   Some cells are pre-filled in purple which indicates that public infrastructure is permitted under a SEPP. These cells are still to be filled in with o, c or x for the private infrastructure component:

   - (purple) public infrastructure permitted under a SEPP.

   Note: The SEPP (Transport and Infrastructure) 2021 principally focuses on providing for the delivery of infrastructure or services by local and State government authorities. Most private infrastructure remains regulated under local planning rules (e.g. LEPs). Please refer to LEP Practice Note PN 10-001 Zoning for Infrastructure in LEPs for further details.

5. Leave the columns empty (i.e. keep the cross-hatching as default) for the zones not in use.

6. The matrix is designed to be viewed on-screen. It can also be printed if a hard copy is needed. The following print settings are provided to assist:

   **Recommended print settings:**

   | | **A3** | **A4** |
   |---|---|---|
   | Orientation: | Portrait | Landscape |
   | Scaling: | 1 page wide by 3 pages tall | 1 page wide by 8 pages tall |

## How the SharePoint list holds the matrix (added - not part of the source)

One row per land use term (195 rows), in the same order as the MATRIX sheet. One column per zone.

### Codes in the zone columns

In the blank template every o, c and x is a value mandated under the Standard Instrument (green or red in the spreadsheet). A blank cell is left for the council to fill in.

| Code | Meaning |
|---|---|
| o | permitted without consent [mandated under the SI] |
| c | permitted with consent [mandated under the SI] |
| x | prohibited [mandated under the SI] |
| H | permitted under the SEPP (Housing) 2021 |
| TI | permitted under the SEPP (Transport & Infrastructure) 2021 [public and private infrastructure] (shown as "T I" in the spreadsheet) |
| * | must be included as permitted with or without consent - council selects o or c |
| # | may (but need not) be permitted with consent - council selects c or x |
| PI | purple cell: public infrastructure permitted under a SEPP; the private infrastructure part is still to be filled in with o, c or x |
| (blank) | not set by the template - for the council to fill in (or zone not used) |

### Other columns

| Column | What it holds |
|---|---|
| Title | the land use term (without any "[eg ...]" text) |
| TermAsShown | the term exactly as written in the spreadsheet |
| Examples | the "[eg ...]" text, if any |
| Level | 1 = main term; 2, 3, 4 = sub-terms (from the indent in the spreadsheet) |
| ParentTerm | the term this one sits under |
| Section | the grey heading row it sits under, e.g. "LAND USE terms WITHIN agriculture group term" |
| SortOrder | row order in the spreadsheet |
| TermNote | the comment on the term cell, e.g. "sub-term of agriculture" |
| ZoneNotes | comments on the zone cells, word for word, with the zones they apply to, e.g. "RU1: Must be included as permitted with or without consent - see Direction for Zone RU1 in the SI" |
